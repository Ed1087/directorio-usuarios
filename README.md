# Aurora Libros

Aplicación web desarrollada como proyecto académico
de Programación Web VII.

## Descripción

Aurora Libros es una librería virtual que permite
explorar libros y consultar información de usuarios
y sus publicaciones mediante una API externa.

## Funcionalidades

- Catálogo de libros.
- Búsqueda y filtros.
- Carrito de compras.
- Directorio de usuarios.
- Consulta de publicaciones mediante Fetch API.
- Manejo de errores y estados de carga.

## Tecnologías

- HTML
- CSS
- JavaScript
- JSONPlaceholder API
- Git y GitHub
